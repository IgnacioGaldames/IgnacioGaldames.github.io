El largo de las historias de ficción puede variar significativamente según el género, el público objetivo y el propósito de la narrativa. A continuación, se presentan algunas categorías comunes de longitud para las historias de ficción:

| Categoría | Longitud en palabras |
|-----------|----------------------|
| Ficción flash | 100 - 1000 |
| Ficción corta | menos de 7,500 palabras |
| Noveletta | 7,500-17,500 palabras |
| Novella | 17,500-40,000 palabras |
| Novela | 40,000 palabras y más |
| Novela demasiado corta | bajo 70,000 palabras |
| Novela puede ser muy corta | 70,000 – 79,999 |
| Novela totalmente cool | 80,000 – 89,999 |
| Novela generalmente a salvo | 90,000 – 99,999 |
| Novela puede ser muy larga | 100,000 – 109,999 |
| Novela muy larga | 110,000 palabras y más |
